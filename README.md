# Real-Estate-Data-Analysis-Project
##Project Overview

This project focuses on web scraping, data cleaning, analysis, and dashboard creation using real estate/property listing data collected from online platforms like OLX / 99acres.
The main objective of this project is to extract property data, transform raw data into meaningful insights, and visualize trends through an interactive dashboard.

##Features
- Automated Web Scraping using Selenium
- Extracted property details such as:
- Property Title
- Location
- Price
- Area Information
- Data Cleaning & Transformation
- Exploratory Data Analysis (EDA)
- Interactive Dashboard Creation
- CSV Export for further analysis
